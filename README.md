# bare_app

GUI-приложение для OdroidLinux SDK на LVGL. Первая цель — ODROID-GO Advance:
экран, кнопки и стик. Архитектура рассчитана на добавление плат и оборудования
и на замену LVGL другим тулкитом: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Репозиторий подключается к SDK сабмодулем `apps/bare_app`. Сабмодули внутри:
LVGL (v9.6.0) — `third_party/lvgl`, doomgeneric — `ports/doom/doomgeneric` (нужен
только для `GAME_DOOM`):

```sh
git submodule update --init --recursive apps/bare_app      # из корня SDK
```

## Лицензии

Всё, кроме каталога [`ports/doom/`](ports/doom/), — код bare_app. В `ports/doom/` лежит
Doom под GPLv2: из него собирается отдельная программа `bare_app_doom`, которая
в `bare_app` не линкуется. bare_app запускает её и обменивается с ней только кадрами
и событиями геймпада. Так же устроены Герои III: клиент VCMI (GPLv2) собирает пакет
`vcmi` SDK со своим патчем, а здесь только протокол `src/games/game_ipc.h`.

## Doom

Пункт «Doom» в главном меню (символ `GAME_DOOM` в Kconfig, включён в `oga_defconfig`
и `pc_defconfig`). Движок [doomgeneric](https://github.com/ozkl/doomgeneric) (GPLv2)
собирается из `ports/doom/` в отдельную программу `bare_app_doom`, которая ставится рядом
с `bare_app`. Движок хранит состояние в глобальных переменных и выходит через `exit()`,
поэтому на каждую игру запускается новый процесс. Падение игры не роняет приложение,
а лицензия GPL не распространяется на `bare_app`.

- Игра рисует кадры 320×200, растянутые до 4:3 по высоте экрана, в общую память
  (memfd, тройной буфер без блокировок). Приложение кладёт их в видеослой (на OGA —
  плоскость DRM). Кнопки идут в игру через сокет (`src/games/game_ipc.h`).
- Нужен видеослой: DRM на плате, `pc-mem` на ПК. В окне SDL и на fbdev экран покажет
  сообщение.
- Звуковые эффекты игра выводит сама (`ports/doom/doom_sound.c`, ALSA без SDL) на
  устройство из таблицы платформы (`-pcm /dev/snd/pcmC0D0p` на OGA). На ПК игра
  запускается с `-nosound`. Музыки и сети нет.
- IWAD: `GAME_DOOM_WAD` (по умолчанию `/usr/share/games/doom/doom1.wad`), во время работы
  его можно заменить через `BARE_APP_DOOM_WAD`. Настройки и сохранения хранятся
  в `GAME_DOOM_DIR` (`~/.local/share/bare_app/doom`).
- Из игры в меню приложения возвращают F5 или пункт Quit Game в меню Doom.
  Удержание F6 закрывает всё приложение. Если игра не запустилась или упала, экран покажет причину.

| Кнопка | В игре | В меню Doom |
|---|---|---|
| крестовина / стик | ходьба, поворот | выбор пункта |
| A | огонь | Enter («y» в вопросе да/нет) |
| B | использовать (двери, кнопки) | назад |
| X | бег (удерживать) | |
| Y | следующее оружие | |
| L1 / R1 | шаг влево / вправо | |
| L2 | карта | |
| R2 | огонь | |
| F1 (Start) | меню Doom | закрыть |
| F2 / F3 | сохранить / загрузить | |
| F4 | пауза | |
| F5 | выйти в меню bare_app | |

На ПК (shareware-WAD можно взять в пакете `doom1-wad` SDK):

```sh
echo "wait:500 a wait:3000 f6" | BARE_APP_DOOM_WAD=doom1.wad BARE_APP_SHOT=doom.ppm \
    build-host/bare_app -p pc-mem
```

## Герои III (VCMI)

Пункт «Герои III» в главном меню (`GAME_HOMM3`, включён в `oga_defconfig`). Игра — клиент
[VCMI](https://vcmi.eu/), открытого движка Heroes of Might and Magic III. Его собирает пакет
`vcmi` SDK (`APPS_CONFIG += bare-app.HOMM3=y`) с патчем связи с bare_app. Данные игры в
образ не входят: `scripts/homm3-install.sh` SDK копирует на плату файлы оригинальной игры
(Shadow of Death или Complete) и мод Horn of the Abyss для VCMI в `/data/vcmi`.

- VCMI рисует программно в окно в памяти (видеодрайвер SDL `dummy`) размером вдвое
  больше экрана, 960×640. На экран оно попадает целиком, уменьшенное вдвое, или
  куском 1:1 вокруг курсора («лупа»). L1 переключает режимы.
- Крестовина в обзоре прокручивает карту приключений, где бы ни был курсор (в других
  окнах — листает списки), в лупе двигает саму лупу; сдвиньте стик, и лупа вернётся
  к курсору.
- У края экрана карта прокручивается, только пока стик наклонён к этому краю: курсор,
  оставленный у края, её не двигает.
- Музыка и звуки идут через alsa-lib на устройство из таблицы платформы.
- Язык игры — язык bare_app (Настройки → Язык): тексты VCMI и модов, а с модом
  перевода (`russian-translation`, его ставит скрипт SDK) и тексты самой игры.
  Смена языка действует с ближайшего запуска игры. Тексты карт и кампаний остаются
  такими, какими их записали: карты русского издания и на английском будут русскими.
- Загрузка с HotA занимает около 10 секунд, всё это время на экране «Загрузка...».
- Если нет VCMI или данных, экран напишет, чего не хватает.

| Кнопка | Действие |
|---|---|
| стик | курсор |
| A | левый клик |
| Y | правый клик (удерживать — подсказка) |
| B | открыть выбранного героя, OK в окнах |
| крестовина | прокрутка карты; в лупе — движение лупы |
| F2 (Select) | отмена (Esc) |
| X | конец хода, в бою — автобой |
| R1 | следующий герой, в бою — защита |
| L2 / R2 | громкость тише / громче |
| F1 (Start) | настройки |
| L1 | обзор / лупа |
| F5 | выйти в меню bare_app |

## Состав сборки (Kconfig)

Что входит в бинарник — платформы, драйверы, сервисы, экраны, шрифты, языки,
отладка, — задаёт `Kconfig` (Kconfiglib лежит в `tools/kconfig`, нужен только `python3`).
Готовые наборы в `configs/`:

| defconfig | Для чего |
|---|---|
| `pc_defconfig` | сборка на ПК (по умолчанию): симулятор SDL, `pc-mem`, платформа OGA, тесты |
| `oga_defconfig` | образ OGA (по умолчанию при кросс-сборке и в пакете Buildroot) |
| `oga_minimal_defconfig` | пример урезанной сборки: fbdev, только английский, без слоёв и настроек |

```sh
cmake -S . -B build-host -DBARE_APP_DEFCONFIG=pc_defconfig   # имя из configs/ или путь
make -C build-host menuconfig          # поменять состав; следующая сборка его подхватит
make -C build-host update-defconfig    # сохранить обратно в выбранный defconfig
make -C build-host savedefconfig       # или в build-host/defconfig
BARE_APP_DEFCONFIG=oga_minimal_defconfig tools/oga.sh run    # другой состав на плате
```

`.config` в каталоге сборки пересоздаётся из defconfig, когда тот изменился или выбран
другой. Правки из `menuconfig` живут до этого момента.

## Сборка и запуск

На ПК. Платформа `pc` открывает окно SDL2 (если при сборке был найден `libsdl2-dev`),
`pc-mem` рисует в память — для тестов и сценариев без окна:

```sh
cmake -S . -B build-host && cmake --build build-host -j
cd build-host && ctest                 # юнит-тесты и smoke-тест без тулкита
./bare_app                             # симулятор в окне
echo "down a wait:500 f6" | BARE_APP_SHOT=shot.ppm ./bare_app -p pc-mem   # сценарий кнопок, снимок экрана
```

На ODROID-GO Advance через консоль (`scripts/oga-serial.py` SDK, плата на `/dev/ttyUSB0`).
Нужен собранный тулчейн прошивки (`make FW=oga rootfs` в SDK):

```sh
tools/oga.sh run            # собрать, скопировать в /tmp/ изменившиеся bare_app и
                            # bare_app_doom, запустить
tools/oga.sh key down a     # нажать кнопки
tools/oga.sh shot s.png     # снимок всех слоёв работающего приложения (SIGUSR1)
tools/oga.sh stop           # остановить, показать конец лога
tools/oga.sh wad doom1.wad  # положить IWAD в /usr/share/games/doom/ (через консоль — минуты)
```

Опции программы: `-p PLATFORM` (без него — по device tree), `-b lvgl|headless`,
`-L en|ru` — язык (или `BARE_APP_LANG`), `-v` — отладочный лог.
На OGA экран выводится через DRM с аппаратными плоскостями (видео под UI, экран «Layers»),
если DRM недоступен — через fbdev. Снимок: `kill -USR1 $(pidof bare_app)` → `/tmp/bare_app.ppm`
(или `BARE_APP_SHOT`).
Выход: удержание F6 (`quit_combo` платформы) 2 секунды — пока кнопка нажата, на экране
предупреждение, отпустить раньше — отмена; SIGTERM/SIGINT. Пункт меню «Выход» на платформе
с командой `poweroff` (OGA: `/sbin/poweroff`) после выхода выключает устройство,
на ПК просто закрывает приложение.
Кнопка питания работает везде, и в игре тоже. Короткое нажатие — сон: сначала гаснет
только экран, а другие кнопки перестают действовать; нажатие кнопки питания возвращает
экран. Через 10 секунд с погашенным экраном устройство засыпает по-настоящему командой
`suspend` платформы (OGA: `/usr/sbin/pm-suspend` из SDK: сон в RAM, светодиоды гаснут),
просыпается от нажатия кнопки питания; это нажатие не усыпляет снова. Удержание 2 секунды
выключает устройство, как пункт «Выход»: после полсекунды на экране предупреждение,
отпустить тогда — отмена.

Шрифты с кириллицей пересоздаются так (нужен Pillow):

```sh
for s in 14 20; do tools/gen_font.py --size $s --name ui_font_$s \
    --fallback lv_font_montserrat_$s -o src/gui/view/lvgl/fonts/ui_font_$s.c; done
```

## Звук и Wi-Fi

Экран «Настройки»: громкость, вывод звука (авто — по штекеру наушников, динамик,
наушники), строка Wi-Fi открывает экран сетей: вкл/выкл, состояние и адрес, сети
рядом, подключение (ключ новой сети вводится на экранной клавиатуре) и «забыть».
Громкость, вывод и вкл/выкл Wi-Fi хранятся в файле настроек. При смене громкости
звучит короткий сигнал новой громкости (`SOUND_FEEDBACK`).

- Звук — ioctl управляющего устройства ALSA (`/dev/snd/controlC0`), без alsa-lib.
  Имена регуляторов задаёт таблица платформы. У кодека OGA (rk817) выход сам по
  штекеру не переключается, это делает `bare_app` в режиме «авто». Сигнал громкости
  выводится через ioctl устройства PCM; устройство освобождается через секунду
  после сигнала, чтобы его мог взять Doom.
- Wi-Fi — управляющий сокет работающего `wpa_supplicant` (как у `wpa_cli`, без
  libwpa_client). Сети и ключи хранит он сам (`update_config=1`). Адрес получает
  системный DHCP-клиент: в образе OGA его перезапускает `/etc/wpa_cli.action` при
  подключении к другой сети. Новый ключ сначала проверяется отдельной записью, так
  что опечатка не портит сохранённую сеть.
- На ПК (`pc`, `pc-mem`) оба устройства — имитация (`src/drivers/sim.c`): несколько
  выдуманных сетей, верный ключ — любой от 8 символов, начинающийся с `pass`.

## Управление

| Кнопка | Действие |
|---|---|
| крестовина / стик вверх-вниз | перемещение фокуса |
| влево / вправо | значение у виджета в фокусе (ползунок) |
| A | нажать |
| B | назад (на экране теста ввода — дважды) |
| L1 / R1 | предыдущий / следующий виджет |
| X | второе действие: забыть сеть Wi-Fi (дважды), стереть символ на экранной клавиатуре |
| L2 / R2 | громкость тише / громче (кроме теста ввода и Doom) |
| громкость + / − | громкость с любого экрана, и в игре (если у платы есть эти кнопки; у OGA Black Edition их нет) |
| питание (коротко) | сон: экран гаснет, через 10 с настоящий сон; вернуть экран / проснуться |
| питание (удерживать 2 с) | выключить |
| F6 (удерживать 2 с) | выход |

На экранной клавиатуре крестовина ходит по клавишам, A печатает, ✓ подключает.

В симуляторе SDL: стрелки, X = A, Z/Esc = B, S = X, A = Y, Q/W = L1/R1, 1…6 = F1…F6.
